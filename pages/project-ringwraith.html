OVERVIEW

A complete flight build

Ringwraith is a documented first quadcopter build, from choosing the parts and soldering the stack to configuring Betaflight and flying line of sight.

The build uses a Mark4 HD 5-inch, 240 mm carbon-fiber frame, four 2207 1800KV motors, a 6S 1300mAh LiPo battery, and a JHEMCU F722 flight stack. A SpeedyBee Nano ExpressLRS receiver connects the quad to a Radiomaster Pocket transmitter over a 2.4 GHz control link.

There is no video system yet, so the first flights are line of sight. The repository records the wiring, configuration, battery care, flying notes, and next upgrade ideas.

HARDWARE

Choosing the system

Frame and propulsion

The Mark4 HD 5-inch H-style carbon-fiber frame carries four iFlight XING-E Pro 2207 1800KV motors and 5-inch tri-blade props.

Flight stack

A JHEMCU GF30F722-ICM flight controller and RuiBet BLHeli_S 4-in-1 ESC form the control and motor-power stack.

Radio link

A SpeedyBee Nano 2.4 GHz ExpressLRS receiver communicates with the Radiomaster Pocket using CRSF over UART.

Power and protection

The 6S battery connects through an XT60 pigtail, with a low-ESR capacitor across the battery pads and separate attention to battery safety.

FLIGHT CONTROLLER

What the F722 provides

The JHEMCU GF30F722-ICM gives the quad room for both current flight control and future expansion.

Processor and sensingSTM32F722 processor with an ICM-42688-P gyro.

Power range3–8S input with regulated 5V and 10V outputs; the 10V rail is intended for a future HD video unit.

Diagnostics16MB blackbox storage and an AT7456E analog OSD chip support flight review and configuration.

ExpansionSix UARTs, I2C, LED strip and buzzer pads, an HD port, USB-C, and a boot button.

SOFTWARE

Configuring the aircraft

Betaflight handles the flight controller configuration, motor layout, receiver link, arming behavior, modes, and flight tuning. The build notes emphasize checking the physical setup before applying power and confirming every motor direction in the Motors tab.

  • Stack orientation is documented so the flight controller arrow points forward and the ESC battery pads face the rear.
  • The receiver uses a crossed TX/RX UART connection and is powered from the flight controller's 5V pad.
  • The motor layout follows Betaflight's default props-in arrangement, with motor direction verified before propellers are installed.
  • The repository records the Radiomaster Pocket and EdgeTX setup for the ExpressLRS control link.

FIRST FLIGHTS

Learning to fly safely

Ringwraith was first flown line of sight because the build does not yet include a video system. That keeps the early testing focused on the airframe, control link, motor response, and battery behavior.

The build notes cover arming checks, failsafe behavior, propeller direction, LiPo charging and storage, and the difference between a controlled short test and a longer flight. Video and an HD system are planned as future upgrades.

LESSONS

What the build taught me

A quadcopter build is a chain of small decisions where wiring, firmware, radio setup, power, and mechanical assembly all meet.

  • Small signal pads need the right wire size and careful soldering.
  • Correct stack orientation and motor mapping prevent software configuration from hiding a physical wiring mistake.
  • Battery voltage, capacitor placement, receiver power, and failsafe behavior all matter before a first flight.
  • Documenting the build makes later upgrades, troubleshooting, and safe repeatable tests much easier.
